# Flashcard Quiz App

A simple and interactive Flashcard Quiz App built using HTML, CSS, and JavaScript. This application helps users study and revise concepts using customizable digital flashcards.

## Features

- Display questions and answers using flashcards
- Show and hide answers
- Navigate using Next and Previous buttons
- Add new flashcards
- Edit existing flashcards
- Delete flashcards
- Display current card number
- Responsive and mobile-friendly design
- Clean and modern user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open index.html.
4. Right-click and select "Open with Live Server".
5. The application will open in your browser.

You can also open index.html directly in your browser.

## How to Use

1. Read the question displayed on the flashcard.
2. Click "Show Answer" to reveal the answer.
3. Use "Next" and "Previous" to navigate between cards.
4. Click "Add Card" to create a new flashcard.
5. Click "Edit" to modify the current flashcard.
6. Click "Delete" to remove the current flashcard.
